# OnaStop Desktop
## La herramienta más importante del tiempo moderno 💀
### Funcionalidades:
- Bloquear ejecutables por nombre
- Bloquear páginas web por dominio
- Detección y bloqueo automático de juegos para adultos de Steam

### Cómo usar este software:
- Inicialización y bloqueo
1. Crea un archivo llamado contrasena.key en la misma carpeta que el ejecutable ServerAuth
2. En el archivo introduce una contraseña segura, encriptada con bcrypt
3. Ejecuta el archivo principal y bloquea la función que necesites
- Desbloqueo
1. Para desactivar el bloqueo necesitas ejecutar el ServerAuth, y en el cliente, introducir la contraseña anteriormente guardada para recibir un código temporal
2. Introduce el código temporal en el programa para desbloquearlo
